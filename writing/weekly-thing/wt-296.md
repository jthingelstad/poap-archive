### [Ethereum Follow Protocol](https://ethfollow.xyz/)

Interesting new protocol for Ethereum that allows you to create a follower concept directly on the blockchain. You follow other wallets by address or ENS name. You can add tags to them as well. The EFP website then lets you follow all transactions for those addresses, but you could build any number of other applications on top of this data. I created an initial set of accounts to follow and it [mints an NFT](https://rainbow.me/profile/thingelstad.eth?nft=base_0x0E688f5DCa4a0a4729946ACbC44C792341714e08_6256) that stores the follower data. If you create a follow group early you can graph a [EFP Early 2024](https://poap.gallery/drop/178066) POAP. I got mine!
